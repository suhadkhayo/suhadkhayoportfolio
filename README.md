# Creative Portfolio Website

A responsive multi-page portfolio website made with plain HTML and CSS.

## Pages
- `index.html` — home page
- `projects.html` — all five projects
- `about.html` — about page
- `contact.html` — contact page
- Five individual project pages

## Before publishing
1. Open `contact.html` and replace `yourname@example.com` with your email address.
2. Open `about.html` and personalize the introduction if you'd like.
3. You can change the site title in the header by editing `YOUR PORTFOLIO` in each HTML page.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `my-portfolio`).
2. Unzip this folder on your computer.
3. Upload **everything inside** the `creative-portfolio` folder to the repository's main/root level. Keep the `assets` folder and its images together.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. Wait a minute or two, then refresh the Pages section. GitHub will show your live website link.

No build tools or installation are required.
